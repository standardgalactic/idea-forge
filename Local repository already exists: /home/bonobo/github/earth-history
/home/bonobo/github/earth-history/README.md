# Earth History

Structured computational exploration of geological, climatic, and evolutionary history through reproducible datasets and visualizations.

## Overview

Earth History transforms geological time into structured computational data. The project integrates geological periods, extinction events, continental drift, climate transitions, evolutionary innovations, and atmospheric change into a unified timeline for exploration, analysis, and visualization.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

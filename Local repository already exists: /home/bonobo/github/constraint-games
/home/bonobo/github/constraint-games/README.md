# Constraint Games

Collection of classic logic puzzles implemented using constraint satisfaction, search algorithms, and optimization techniques.

## Overview

Constraint Games is a computational laboratory for studying logic puzzles as formal search spaces. It explores Sudoku, Kakuro, Nonograms, Slitherlink, Lights Out, and related problems through exhaustive search, constraint propagation, SAT methods, heuristic search, and stochastic optimization.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

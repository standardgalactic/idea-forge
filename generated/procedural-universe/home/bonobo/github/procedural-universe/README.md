# Procedural Universe

Deterministic procedural generation of planets, ecosystems, civilizations, cultures, technologies, and historical timelines.

## Overview

Procedural Universe is a deterministic world-generation laboratory that constructs complete fictional worlds from reproducible seeds, including planetary systems, climates, ecosystems, cultures, languages, technologies, writing systems, and simulated historical development.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

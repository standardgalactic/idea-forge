# Tiny Operating Systems

Collection of miniature operating-system implementations illustrating individual systems concepts through self-contained examples.

## Overview

Tiny Operating Systems develops a collection of deliberately small operating systems, each focused on a single systems concept such as scheduling, memory management, interrupts, virtual memory, filesystems, interprocess communication, capability security, or device abstraction.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

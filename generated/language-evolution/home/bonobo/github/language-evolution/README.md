# Language Evolution

Simulation of phonological, lexical, grammatical, semantic, and genealogical language change over time.

## Overview

Language Evolution is a computational laboratory for historical linguistics. It models sound change, lexical replacement, borrowing, semantic drift, grammaticalization, analogy, and language divergence to investigate the long-term evolution of linguistic systems.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

# Math Machines

Collection of executable mathematical models of computation, formal languages, automata, logic, and symbolic reasoning.

## Overview

Math Machines provides executable implementations of classical computational models including finite automata, Turing machines, register machines, lambda calculus, combinatory logic, cellular automata, tag systems, Post systems, and term rewriting, accompanied by visualization, benchmarks, and educational examples.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

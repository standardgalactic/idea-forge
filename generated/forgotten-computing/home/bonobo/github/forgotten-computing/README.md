# Forgotten Computing

Preservation and exploration of historical programming languages, computing systems, and influential software ideas.

## Overview

Forgotten Computing revisits historically significant programming languages, operating systems, computing architectures, and interaction models that continue to offer valuable insights despite no longer being mainstream technologies.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

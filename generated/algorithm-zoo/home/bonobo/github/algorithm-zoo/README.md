# Algorithm Zoo

Reference implementations, benchmarks, and educational comparisons across major families of computer algorithms.

## Overview

Algorithm Zoo is a comparative reference for algorithms implemented with an emphasis on clarity, reproducibility, instrumentation, and experimentation. The repository spans graph algorithms, numerical methods, optimization, computational geometry, dynamic programming, compression, probabilistic methods, and machine learning.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release

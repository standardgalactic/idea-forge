# Microbiology Sim

Educational simulation framework for microbial ecology, colony dynamics, adaptation, and evolutionary processes.

## Overview

Microbiology Sim is a computational laboratory for modeling simplified microbial populations. Planned simulations include colony growth, nutrient competition, quorum sensing, plasmid transfer, antibiotic resistance, mutation, biofilm formation, and ecological interactions.

## Development

This repository uses a standard make interface:

- make init
- make lint
- make test
- make benchmark
- make docs
- make format
- make release
